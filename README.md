# 🍔 Food Delivery Analytics, Recommendation & Forecasting

## 📌 Project Overview

This project performs end-to-end analysis of food delivery data to understand customer ordering behavior, identify popular food combinations, generate food recommendations, and forecast future sales.

The project covers:
- Data loading and exploration
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Association Rule Mining using Apriori
- Food recommendation system
- Time series forecasting using ARIMA
- FastAPI recommendation API
- Docker deployment

## 🎯 Problem Statement

A food delivery company wants to analyze customer ordering behavior, identify popular food combinations, recommend relevant food items, and forecast future order demand.

This project uses data analysis, market basket analysis, recommendation generation, and sales forecasting to provide useful insights into food delivery operations.

## 🛒 Transaction Basket Creation

During data exploration, every `OrderID` was found to contain only one unique food item. Therefore, using `OrderID` directly would not produce meaningful multi-item associations.

`CustomerID` was used as the basket identifier so that food items purchased by the same customer across multiple orders could be analyzed together.

```python
transactions = (
    df_clean.groupby("CustomerID")["FoodItem"]
    .apply(lambda x: list(set(x)))
    .tolist()
)
```

Transactions were encoded using `TransactionEncoder`, followed by Apriori frequent-itemset generation and association-rule generation.

The resulting rules are stored in:

```text
Outputs/association_rules.csv
```
